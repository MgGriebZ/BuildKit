# BuildKit
Chat -> Work -> Code - Practical AI-building education through free community classes and personalized build seminars, supported by reusable follow-along materials.

## Current planning packet

Start with [the launch brief](docs/planning/00-START-HERE.md), [personal seminar PRD](docs/planning/11-PRD-SEMINAR.md) and [outstanding launch items](docs/planning/10-READINESS.md). Revision 0.4 centers personalized one-hour seminars: visual explanations, a working product, a guided refinement and an included Build Kit. Price, policies and live operations remain open. Standalone course sales are deferred.

Free one-hour public/event classes are a core early outreach activity, sharing the reusable demonstration foundation with paid personalized seminars. Plan from a starting commitment of 5–10 owner hours/week, with room to grow rather than a fixed ceiling. See the community PRD and execution queue in the planning packet.

This public repository contains requirements. See [public/private content boundaries](docs/planning/12-REPOSITORY-BOUNDARY.md) before adding any presenter scripts, exclusive teaching material or client files.

The original [BuildKit-PRD.md](BuildKit-PRD.md) remains source material. Its platform architecture, pricing promises, release sequence, and embedded commands are not current execution authority.
