# BuildKit
Chat -> Work -> Code - It's about planning, building, and letting agents run code for you. This is a written course to help explain how a basic user can go from knowing absolutely nothing about "AI" tools such as Claude or ChatGPT to using them as software development tools for building small prototype apps and websites.
