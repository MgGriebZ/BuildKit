# BuildKit
Chat -> Work -> Code - Practical AI-building education through free community classes and personalized build seminars, supported by reusable follow-along materials.

## Current planning packet

Start with [the launch brief](docs/planning/00-START-HERE.md), [personal seminar PRD](docs/planning/11-PRD-SEMINAR.md), [Cozy Room PRD](docs/planning/13-PRD-COZY-ROOM.md) and [outstanding launch items](docs/planning/10-READINESS.md). Revision 0.5 centers seminar-led 60-minute teaching. The standalone bedroom-inspired Cozy Room and free follow-along now have implementation and review branches: [R1 baseline, PR #4](https://github.com/MgGriebZ/BuildKit/pull/4), [R2 refinement, PR #5](https://github.com/MgGriebZ/BuildKit/pull/5), [L2 guide, PR #6](https://github.com/MgGriebZ/BuildKit/pull/6), and [beginner exercise/status update, PR #7](https://github.com/MgGriebZ/BuildKit/pull/7). Price, policies, first host and booking windows also remain open. Paid standalone course/LMS sales are deferred.

Free one-hour public/event classes are a core early outreach activity, sharing the reusable demonstration foundation with paid personalized seminars. Plan from a starting commitment of 5–10 owner hours/week, with room to grow rather than a fixed ceiling. See the community PRD and execution queue in the planning packet.

This public repository owns the standalone example at `examples/cozy-room` and follow-along at `lessons/free/cozy-room`, currently under review in PRs #4–#7. The private presenter-kit update is also under review in the selected authoring repository. PocketPlayroom remains the full product/reference and its private source is unchanged. See [public/private content boundaries](docs/planning/12-REPOSITORY-BOUNDARY.md) before adding presenter scripts, exclusive teaching material or client files. Client sharing is a separate decision.

The canonical room requirements and bounded handoff are [13-PRD-COZY-ROOM.md](docs/planning/13-PRD-COZY-ROOM.md) and [14-EXECUTION-HANDOFF.md](docs/planning/14-EXECUTION-HANDOFF.md). The original [BuildKit-PRD.md](BuildKit-PRD.md) remains historical source material; its platform architecture, pricing promises, release sequence and embedded commands are not current execution authority.
