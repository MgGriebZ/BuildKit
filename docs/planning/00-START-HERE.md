# Build with GriebZ: your first AI build

Revision 0.6 · September 28, 2026 · Owner-directed product pivot; implementation and commercial choices distinguished below.

## Accepted direction

Teach an accessible introduction to AI, then bring the ideas to life through Matt prompting, checking and improving a browser game in front of the audience. Explain terminology along the way. Real bugs and deployment friction can teach useful lessons when handled with a planned recovery path.

Produce a concise standalone guide that works without attending the talk and supports a loose one-hour class with optional deeper material. Free community classes remain a core outreach activity; personal help is an additional offer. This supersedes revision 0.5's indefinite deferral of standalone guide sales and a seminar centered on changing one CSS color.

## Working first example

Use the independent Blazor Cozy Room already built in this repo. The planner's proposed R3 demonstration adds a three-star collection mini-game to R2 through visible AI prompts. It provides a behavior change, progress, completion, replay and checks. The palette edit remains optional practice. PocketPlayroom may be shown as context; its private source is not included in the kit.

A 60-minute core covers AI basics, language/models/cost, the baseline, a substantial live build, checking/repair, a short sharing explanation and next steps. Creating Azure resources is an optional extended lab. Limited Azure capacity does not block a local lesson.

## Boundaries and decisions

The first standalone product is proposed as an accessible one-time purchase; exact price, formats, delivery and support/update policy are open. A $19 USD first-edition price is a planner recommendation for review, not an approved checkout price or market validation. The prior $75 personal-session idea is separate and unapproved.

No revenue forecast or bestseller status is claimed. Maintain the owner's initial 5–10 hours/week planning range with room to expand. A useful free class need not convert into a sale to be valuable.

Public requirements/examples belong here; full paid prose, prompts selected for private teaching and presenter authoring belong in BuildWithGriebZ. Client records stay outside Git. Requirements publication does not create a hosting resource, deploy a product, activate checkout or send outreach.
